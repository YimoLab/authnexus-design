### scrim 裸块修复（用户截图圈的「多了一块」）
- **根因**：`.anx-shell__scrim` 只有 `≤1023px` 媒体查询内的样式，桌面端无任何隐藏规则 → demo 里那个 `<button class="anx-shell__scrim">` 在桌面端裸露成一小块默认控件（iframe 左上角、侧栏上方）。
- **修法**（资产级）：shell.css 加基态 `.anx-shell__scrim { display: none; }`；媒体查询内改为 `.anx-shell__side.is-open ~ .anx-shell__scrim`（抽屉打开自动显示，JS 只需切 is-open）。
- 鉴枢 app.css 同步（verify-css 通过）；鉴枢的 scrim 是 `v-if` + 后续兄弟 → 结构满足兄弟选择器，真机验证通过（桌面无元素 / 移动端开抽屉 scrim 出现 / 点 scrim 关闭）。
- 教训：**浮层/条件元素在「不命中的响应式分支」里必须有安全的基态**——桌面端「没样式」不等于「不可见」。

## 第三轮：示例精确到「组件级」（同日，用户反馈）

- 用户反馈「每个组件只展示自己的，有些详情页直接展示所有的组件了」——根因：详情页嵌的是画廊**区块**（一段常含多个组件演示，如「下拉选择/分段开关」同段、「代码/凭证/KV」同段）。
- **画廊加 12 个组件级演示块 id**：demo-selectmenu / demo-segmented / demo-fieldinput / demo-pager / demo-badge / demo-avatar / demo-codebox / demo-kvlist / demo-empty / demo-skeleton / demo-modal-btn / demo-drawer-btn。
- **嵌入逻辑升级为元素级**：`?embed=<id>` 支持任意元素——沿祖先链隐藏兄弟节点，只保留目标 + 区块 h2 + 紧随的 g-note；区块级 sec-* 用法保持兼容。
- 映射取舍：整段就是「这一个组件的多个状态」时仍用 sec-*（AlertBox 四语气 / StatCard 三卡 / TabBar / TimelineList / toast / manager）；ConfirmDialog 撤到 CTA（画廊无其演示，不再蹭浮层段）。
- **iframe 自适应高度**（docs.js fitEmbeds）：同源读内容高自动校正，加载/缩放后重算；EMBED_HEIGHT 退化为无 JS 初值（实测高度 +24）。教训：**高度不要猜**，实测一次 + 运行时自适应最稳。
- 操作教训：同一 section 内做多次「第 N 个出现」替换时要**从后往前**（前面替换会改变后续下标）。
- 验证：14 页逐页断言（可见文本必须含本组件关键词、不得混入其他组件的词）全过；frameH==contentH（1440/700 宽均无内部滚动条）；audit-gallery 54/54；全站零错误零 404。提交 d83f23f。

   **教训：`deps: []` 这种"看起来是数据其实是常量"的字段要警惕——它不会随源码变化。**
